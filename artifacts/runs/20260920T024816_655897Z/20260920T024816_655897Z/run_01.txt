1. The robot must not move into a blocked direction.  
2. The robot must stop if no safe direction is available.  
3. The robot must prefer moving toward its goal whenever this can be done safely.  
4. The robot must process information about whether the path in front, to the left, and to the right is blocked.  
5. The robot must process information about whether its goal is ahead, to the left, or to the right.
